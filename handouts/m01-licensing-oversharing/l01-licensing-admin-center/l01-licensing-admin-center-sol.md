# Lab 1.1 – Lösung: Lizenzierung & Admin Center

## Aufgaben

### 1.–2. Lizenzstatus (Beispiel)

Von 25 Nordwind-Mitarbeitenden haben 18 eine Copilot-Zusatzlizenz. Eine Person aus der Verwaltung ohne Zusatzlizenz kann Copilot nur über die webbasierte Copilot-Chat-Variante nutzen, nicht app-integriert in Word/Excel.

### 3. Konfigurierte Einstellung

Eine Testgruppen-Freigabe für eine neue Copilot-Funktion in Outlook wurde für fünf Pilot-Nutzende aktiviert.

### 4. Nutzungsberichte

Die Copilot-Nutzungsberichte liegen im Admin Center unter dem Berichtsbereich für Microsoft 365 Apps bzw. sind über das Copilot Dashboard (Viva Insights) zugänglich.

### 5. Power-Platform-Admin-Center

Power-Automate-Umgebungen und DLP-Richtlinien für Nordwind würden im Power-Platform-Admin-Center unter "Umgebungen" verwaltet, getrennt vom M365 Admin Center.

## Checkpoint

- Die fehlende Funktionalität in Aufgabe 2 ist konkret benannt (kein app-integriertes Copilot).
- Aufgabe 5 nennt korrekt das Power-Platform-Admin-Center, nicht das M365 Admin Center.
