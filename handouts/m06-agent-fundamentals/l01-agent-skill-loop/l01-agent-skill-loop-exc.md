# Lab 6.1 – Übung: Nordwind-Aufgaben klassifizieren

## Ausgangslage

Nordwind Consulting sammelt mehrere Ideen für KI-Unterstützung. Vor dem Bauen wird jede Idee nach Aufwand, Datenlage, Wiederholung und Verantwortung eingeordnet.

## Zielartefakt

Eine Klassifizierungsmatrix mit Begründung und benötigtem Baustein entsteht. Die Nordwind-Projektbasis wird nicht verändert.

## Voraussetzungen und Starter

- Theorie aus Lab 6.1
- Nordwind-Kontext aus `../../project/nordwind-it-richtlinie.md` und `../../project/nordwind-onboarding-leitfaden.md`
- Leere Matrix im eigenen Notizdokument oder Kursboard

## Aufgaben

1. Matrix mit diesen Spalten anlegen: Aufgabe, Einordnung, Begründung, benötigter Baustein, offene Prüfung.
2. Die sechs Nordwind-Aufgaben klassifizieren:
   - A: eine einmalige Ausschreibung in drei Entscheidungspunkte verdichten,
   - B: täglich Fragen zu VPN, Erstlogin und Standardsoftware beantworten,
   - C: aus einer Onboarding-Frage eine Schritt-für-Schritt-Checkliste erstellen,
   - D: einen Gerätewechsel im Ticketsystem auslösen,
   - E: eine individuelle Gehalts- oder Vertragsfrage beantworten,
   - F: eine Absage-Mail für einen einmaligen Bewerbungsfall höflicher formulieren.
3. Für jede Aufgabe eine Kategorie wählen: reiner Prompt, Chat-Agent, Agent mit Tools/Skills oder bewusst kein Agent.
4. Pro Aufgabe eine Begründung mit mindestens zwei Kriterien notieren: Wiederholung, Datenlage, Risiko, Aktion, Verantwortlichkeit.
5. Für alle Agent-Kandidaten den wichtigsten Baustein benennen: Instruktion, Wissen, Tool oder Skill.
6. Eine Aufgabe markieren, bei der eine menschliche Freigabe zwingend bleibt.

## Checkpoint

- Alle sechs Aufgaben sind eingeordnet.
- Jede Begründung enthält mindestens zwei Kriterien.
- Mindestens eine Aufgabe ist bewusst kein Agent.
- Tool- und Skill-Bedarf sind getrennt benannt.

## Abschlusskriterien

- Die Matrix macht erkennbar, warum der spätere Nordwind IT-Helfer nicht mit einem Prompt gleichgesetzt wird.
- Kritische Entscheidungen bleiben als menschliche Freigabe sichtbar.

## Erweiterung

Eine eigene Aufgabe aus dem Arbeitsalltag ergänzen und mit derselben Matrix klassifizieren.

## Fallback

Ohne Live-Toolzugang reicht die Matrix im Notizdokument. Die Einschränkung: reale Builder-Optionen und Tenant-Governance werden dabei nicht geprüft.
