# Lab 2.5 – Übung: Plattform-Integration

**Ändert die Nordwind-Projektbasis?** Nein — gemeinsame Durchsicht ohne eigene Konfiguration.

## Ausgangslage

Die Plattform-Landkarte aus `01-security-plattform-landkarte.md` liegt vor.

## Aufgaben

1. Im Plenum gemeinsam durchgehen, welche der fünf Produkte (Entra ID, Purview, Defender XDR, Intune, Sentinel) im eigenen Unternehmen bereits genutzt werden.
2. Für jedes genutzte Produkt festhalten, welches Signal es an Security Copilot liefern könnte.
3. Ein Produkt benennen, das im eigenen Unternehmen fehlt, und einschätzen, welche Signalart dadurch nicht verfügbar wäre.
4. Diskutieren, ob eigenständige oder eingebettete Security-Copilot-Nutzung für den eigenen Arbeitsalltag passender wäre.

## Checkpoint

- Mindestens drei Produkte wurden dem eigenen Unternehmen zugeordnet (genutzt/nicht genutzt).
- Die fehlende Signalart aus Aufgabe 3 ist konkret benannt.

## Abschlusskriterien

- Eine gemeinsame Einordnung der eigenen Plattform-Landkarte liegt vor (informell, keine formale Dokumentation nötig).

## Fallback

Ohne Kenntnis der eigenen Unternehmensplattform: die Diskussion anhand des Nordwind-Beispiels (Entra ID, Purview, Intune vorhanden, Defender XDR und Sentinel nicht) führen.
