# Lab 3.4 – Übung: Nutzungstelemetrie & Copilot Dashboard

**Ändert die Nordwind-Projektbasis?** Nein — es entsteht eine Interpretation der bereitgestellten Beispieldaten.

## Ausgangslage

Ein anonymisierter, vorbereiteter Copilot-Dashboard-Auszug für Nordwind liegt vor: `nordwind-copilot-dashboard-auszug.md` in `handouts/project/` (Kursvoraussetzung).

## Aufgaben

1. Aus dem Dashboard-Auszug die aktive vs. zugewiesene Lizenzquote ablesen.
2. Die Nutzung je App vergleichen: welche App wird am häufigsten, welche am seltensten genutzt?
3. Die Wiederkehrrate ablesen und mit dem Schwellenwert von 40 % nach 4 Wochen vergleichen.
4. Drei Adoptions-Erkenntnisse aus dem Dashboard ableiten, je mit einer konkreten Maßnahme.
5. Prüfen, ob eine der Erkenntnisse eine personenbezogene Auswertung nahelegen würde, und diese bewusst auf Abteilungsebene aggregiert reformulieren.

## Checkpoint

- Alle drei Kennzahlen (Lizenzquote, App-Nutzung, Wiederkehrrate) wurden tatsächlich aus dem Auszug abgelesen.
- Jede der drei Erkenntnisse hat eine konkrete, umsetzbare Maßnahme.
- Aufgabe 5 zeigt eine bewusste Aggregation, keine personenbezogene Formulierung.

## Abschlusskriterien

- Drei dokumentierte Adoptions-Erkenntnisse mit Maßnahme liegen vor.

## Erweiterung

Die abgeleiteten Erkenntnisse mit einem bestehenden Adoptionsplan abgleichen (falls vorhanden): welche Maßnahme ist dort bereits vorgesehen?

## Fallback

Ohne bereitgestellten Dashboard-Auszug: die Übung anhand einer fiktiven Beispieltabelle (3 Apps, 2 Abteilungen, eine Wiederkehrrate von 45 %) durchführen.
