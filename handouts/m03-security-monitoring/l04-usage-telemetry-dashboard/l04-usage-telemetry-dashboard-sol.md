# Lab 3.4 – Lösung: Nutzungstelemetrie & Copilot Dashboard

## Aufgaben

### 1.–3. Kennzahlen (Beispiel-Dashboard)

| Kennzahl                        | Wert                                                          |
| ------------------------------- | ------------------------------------------------------------- |
| Aktive vs. zugewiesene Lizenzen | 14 von 18 aktiv (78 %)                                        |
| Nutzung je App                  | Chat am häufigsten, Excel am seltensten                       |
| Wiederkehrrate                  | 38 % nach 4 Wochen (unter dem 40 %-Schwellenwert) |

### 4. Drei Erkenntnisse mit Maßnahme

1. Wiederkehrrate unter Schwellenwert → zusätzliches Peer-Learning-Angebot.
2. Excel-Nutzung gering → rollenspezifische Kurzschulung zu Excel-Anwendungsfällen.
3. 4 von 18 Lizenzen inaktiv → gezielte Rückfrage bei diesen Personen, ob Zugang/Onboarding fehlt.

### 5. Aggregation prüfen

Die Erkenntnis zu inaktiven Lizenzen wurde bewusst auf Abteilungsebene reformuliert ("Verwaltung zeigt niedrigere Aktivquote als Vertrieb") statt einzelne Namen zu nennen.

## Checkpoint

- Alle drei Kennzahlen sind korrekt aus dem Beispiel-Dashboard abgelesen.
- Jede Maßnahme ist konkret und nicht nur eine allgemeine Absicht.
- Die Reformulierung in Aufgabe 5 vermeidet jede personenbezogene Formulierung.
